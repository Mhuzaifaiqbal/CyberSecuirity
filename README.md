# Cybersecurity Projects Repository

A collection of hands-on cybersecurity and networking projects built in Python to demonstrate practical skills in network security, packet analysis, authentication systems, and intrusion detection.

These projects focus on real-world cybersecurity concepts including ARP scanning, packet sniffing, access-control systems, device monitoring, and security automation.

---

# Projects Included

## 1. Authentication Matrix System

A command-line access control and authorization management system implementing domain/type-based permissions.

### Features

* User authentication and password validation
* Domain-based access control
* Object type classification
* Permission assignment and access verification
* Binary file persistence using Pickle
* Role and operation management

### Concepts Demonstrated

* Authentication systems
* Authorization matrices
* Access-control logic
* Secure permission handling
* Command-line interface design

### Technologies

* Python
* Argparse
* Pickle Serialization

---

## 2. Network Scanner

A lightweight ARP-based network scanner for discovering devices on a local subnet.

### Features

* ARP broadcast scanning
* Live host discovery
* MAC address collection
* Vendor/OUI identification
* Unknown device detection

### Technologies

* Python
* Scapy

---

## 3. HTTP Packet Sniffer

A packet sniffing tool capable of capturing HTTP requests and extracting login-related traffic for educational security analysis.

### Features

* HTTP traffic interception
* URL extraction
* Credential pattern detection
* Real-time packet analysis
* Raw packet inspection using Scapy

### Important Note

This project is intended strictly for:

* Educational purposes
* Ethical hacking labs
* Authorized environments only

### Technologies

* Python
* Scapy
